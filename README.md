One line, at most 200 characters, roasting a smart fridge: it sends a weekly report counting every door open and zero meals cooked, then files a missing yogurt as a missing person.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 111 characters) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
